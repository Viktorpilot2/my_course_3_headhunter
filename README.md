# Проект my_course_3_hh

## Описание:

Проект my_course_3_hh - это тестовое приложение для получения информации о компаниях и вакансиях интегрированное 
с API `HeadHunter`. Проект позволяет получать вакансии, сохранять данные в файл и работать с ними (фильтрация, 
сортировка, поиск). 

## Стек используемых технологий (библиотек):
+ Python 3.12.10
+ poetry
+ psycopg-2
+ dotenv
+ requests

## Установка:

1. Клонируйте репозиторий:
    ```
     https://github.com/ViktorPilot/my_course_headhunter.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Создайте виртуальное окружение командой `poetry install`.
5. Активируйте ВО командой `poetry env activate`.
6. Установите зависимости командой `poetry init`.
7. Программа готова к работе.

## Запуск проекта через главный модуль main.py:

1. Необходимо запустить выполнение программы командой `poetry run python main.py`.
2. В Python файле `main.py` задать:
    + список компаний от которых вы будете получать данные о вакансиях по API в формате: 
   `["Авиакомпания Победа", "Уральские авиалинии, Авиакомпания"]`.
    + название базы данных, куда необходимо сохранять полученные данные в формате: `"my_db"`.
    + слово, по которому будет выведен список всех вакансий, в названии которых содержится это слово в формате: 
   `"руководитель"`. Поиск данных производится без учета регистра заданного слова.
3. В результате получим:
    + список названий компаний и количества вакансий в них в формате: `"Группа ЛСР - 20 вакансий"`.
    + список всех вакансий в формате: `"Компания: Авиакомпания Победа, должность: Делопроизводитель, зарплата: None, 
   ссылка на вакансию: https://api.hh.ru/areas/1"`.
    + среднюю зарплату по вакансиям: `"110816 руб"`.
    + список всех вакансий, у которых зарплата выше средней по всем вакансиям в формате: 
   `"Должность: Бортпроводник, зарплата: 120000 руб."`.
    + список всех вакансий, в названии которых содержится заданное слово в формате:
   `"Руководитель группы поддержки агентских продаж"`.

## Использование отдельных модулей:

### Для модуля api_interaction.py:

1. В Python файле `api_interaction.py` задать:
    + список компаний для поиска в формате: `["Авиакомпания Победа", "Уральские авиалинии, Авиакомпания"]`.
2. Запустить выполнение программы командой `python -m src.api_interaction`.
3. В результате получим:
    + список словарей с данными о компаниях.
    + список словарей с данными о вакансиях этих компаний.

Для остальных модулей отдельное использование не предусмотрено.
